# 示例：从一段视频到一个训练计划

本目录是「视频 → 诊断 → 计划」这套工作流的完整样例，三个文件对应三段产出。

## 文件

| 文件 | 说明 |
|---|---|
| `分析视频示例.mp4` | 输入素材：1280×720 / 27.2s / 30fps，雪道侧后方跟拍，连续滑行。 |
| `诊断输出示例.json` | ① 用 doubao-seed-evolving 分析该视频后得到的结论，整理成结构化格式（问题 + 证据 + 对应教程）。 |
| `训练计划示例.html` | ③ 依据诊断结论检索本知识库后生成的 12 周训练计划，单文件离线可看，含 27 张原文配图。 |

## 三段链路

```
分析视频示例.mp4
      │
      ▼ ① 多模态分析（doubao-seed-evolving）
诊断输出示例.json
      │   水平定位 + 优势 + 4 类问题（每条带视频证据）
      ▼ ② 检索增强（本仓库 71 篇）
映射到教程 04 / 10 / 12 / 13 / 14 / 15 / 16 的对应练习与动图
      │
      ▼ ③ 生成
训练计划示例.html
      三阶段 12 周 · 每个练习可追溯到原文 · 配对照动图
```

## 怎么复现

1. 按主 [README](../README.md#使用方法视频--诊断--训练计划) 里的提示词模板，把自己的视频交给多模态模型
2. 拿到诊断结论后，用主 README 的「诊断关键词 → 教程映射表」定位文章
3. 按「问题 → 教程 → 练习 → 动图 → 周计划」组装输出

## 说明

- `诊断输出示例.json` 是**同一条视频的结论**，只是从训练计划的文字表述整理成了结构化字段，便于机器读取与复用；
  原始分析由多模态模型完成，本仓库不做二次判断。
- 视频为训练记录，已随仓库公开；如涉及他人肖像请自行确认。

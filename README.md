## 使用方法：视频 → 诊断 → 训练计划

这份知识库不是用来「读」的，它是**第二阶段的知识源**。完整链路是三段式：

```
滑雪视频
   │
   ▼  ① 视觉分析
doubao-seed-evolving（多模态大模型）
   │   输出：结构化动作诊断（问题 + 证据 + 水平定位）
   ▼  ② 检索增强
本知识库（71 篇 · 274,053 字 · 755 张图 / 70 个动图）
   │   按「问题关键词」检索到对应教程与示范动图
   ▼  ③ 生成
个性化训练计划（阶段目标 / 周计划 / 动作标准 / 对照动图）
```

### ① 用 doubao-seed-evolving 分析视频

**输入**：一段滑行视频，建议 15–60 秒、侧后方跟拍或固定机位全程不切。

**提示词模板**（可直接复制）：

```text
你是双板滑雪教练。请分析这段滑行视频，按以下固定维度输出，
每个维度必须给出「观察到的现象」和「视频中可验证的证据」：

1. 水平定位：当前处于哪个学习阶段（穿鞋适应 / 直滑降 / 犁式 / 半犁式 /
   基础平行 / 中弯 / 小弯 / 卡宾）
2. 站姿与重心：是否后座、重心是否居中、小腿是否贴鞋舌
3. 立刃与转弯结构：入弯是否主动立刃、弯形是否圆润对称
4. 外脚承重：内板是否承重过多
5. 换弯与点杖：有无引身释压、点杖时机
6. 上半身与板距：是否内倒、有无反弓、板距是否稳定

术语请使用：运动站姿、居中、后座、外脚承重、立刃、搓雪、引身、点杖、
反弓、分离、轴转、上半弯、下半弯。
```

> **关键**：模板里强制要求模型使用上述术语。术语不统一，第 ② 步的检索就会打偏——
> 这个知识库是按作者的术语体系组织的。

**输出示例**：

```json
{"水平定位": "基础平行入门（约等于教程 10–11 阶段）",
 "问题": [
   {"类别": "重心与承重", "表现": "弯末轻微后坐，小腿未持续贴鞋舌",
    "证据": "出弯瞬间雪雾明显增大，板头压力不足"},
   {"类别": "转弯结构", "表现": "入弯阶段雪板保持平板，到下半弯才搓雪",
    "证据": "弯的前半段没有明显刃线"},
   {"类别": "换弯", "表现": "无引身释压，靠上身拧转带动",
    "证据": "换弯前髋膝没有伸展动作"}],
 "优势": ["基础站姿合格，无严重后座", "已脱离犁式，能连续平行大弯"]}
```

### ② 把诊断结果映射到知识库

这一步是**查表**，不是让模型自由发挥。下表把常见诊断结论直接映射到对应文章：

| 诊断关键词 | 去哪篇找 | 关键动作/标准 |
|---|---|---|
| 后座 / 重心落后 | 教程 04、教程 14 | 与重心落后战斗；抬内板、OutsideSkiTurn |
| 外脚承重不足 / 内板承重 | 教程 14 | 鹤弯(StorkTurn)、标枪弯、内脚踏步 |
| 入弯不立刃 / 平板入弯 | 教程 10、教程 12 | 下半弯内脚翻转；先建偏角再立刃 |
| 换弯顿挫 / 无引身 | 教程 13 | 引身→点杖→立刃→转弯的顺序 |
| 弯形不圆 / 速度不稳 | 教程 16 | 结业核心指标：圆润 C 弯 + 诊断表 |
| 小弯节奏 / 翻刃慢 | 教程 08 | 犁式小弯的轴转发力逻辑 |
| 反弓不足 / 上半身内倒 | 教程 15 | 反弓与分离的最小够用幅度 |
| 犁式基础不牢 | 教程 06、教程 09、技术 02 | 犁式转弯原理与半犁式过渡 |
| 站姿根本问题 | 教程 01 | 运动站姿、压鞋舌的误区 |

检索顺序建议：**先分类目录 → 再本表关键词 → 最后读该篇的小标题**。
每篇的 `README` 表格里都有「核心关键词」列，可直接对照。

### ③ 生成训练计划

按「问题 → 对应教程 → 练习动作 → 配套动图 → 周计划」的顺序组装输出，要求：

- 每个练习必须能追溯到某篇教程，**禁止编造原文没有的动作**；找不到就明确写「知识库暂无，待补充」
- 每个练习附上 `media/` 里的对应动图路径，方便对照
- 分阶段给目标与验收标准，不要一上来堆满所有练习
- 参考已有成果：《双板训练计划-手机版.html》（12 周计划 + 27 张配图，单文件离线可看）

> 本仓库附带的训练计划就是按这套流程产出的示例：先用多模态模型分析视频得到问题清单，
> 再按上表检索教程，最后生成的 12 周计划。
